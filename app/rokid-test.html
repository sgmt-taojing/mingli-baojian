📖 Rokid AIUI Host API 参考

HostTakePhoto

调用眼镜摄像头拍照，返回 base64 图片数据
HostTakePhoto() → Promise<{data: string, mimeType: string}>

HostSpeechSpeak

语音播报（TTS）
HostSpeechSpeak(text: string) → Promise<void>

HostSpeechStartRecognition

开始语音识别（ASR）
HostSpeechStartRecognition() → Promise<{text: string}>

HostSpeechStopRecognition

停止语音识别
HostSpeechStopRecognition() → Promise<void>

浏览器降级 API

当 Host API 不可用时，使用 Web 标准 API
navigator.mediaDevices.getUserMedia({video: true, audio: true})
new MediaRecorder(stream)
new SpeechRecognition() / webkitSpeechRecognition()
