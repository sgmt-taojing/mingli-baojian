警 当前发现：4 个 AI 视觉引擎在 launchd plist 中均未配置 API key， 所有视觉请求（图片/中医病历/人脸）只能走 PIL 离线启发式兜底。 KB intent / TTS / STT 等其他路径不受影响。

工 修复方法（复制粘贴即可）

Step 1 · 把以下内容保存到 ~/.zshrc（任选其一）
# ───── 方案 A · g2claw 代理（项目内置，推荐） ─────
export G2CLAW_API_KEY="sk-你的密钥"
export AI_API_BASE="https://api.g2claw.com"

# ───── 方案 B · 智谱 GLM-4V（直接） ─────
export ZHIPU_API_KEY="你的智谱密钥"

# ───── 方案 C · OpenAI GPT-4o ─────
export OPENAI_API_KEY="sk-你的密钥"

# ───── 方案 D · 豆包 ─────
export DOUBAO_API_KEY="你的豆包密钥"
Step 2 · 复制 launchd plist 配置（macOS）
# 备份原文件
cp ~/Library/LaunchAgents/com.mingli-baojian.face-ocr.plist \
   ~/Library/LaunchAgents/com.mingli-baojian.face-ocr.plist.bak.$(date +%s)
