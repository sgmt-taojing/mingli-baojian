👆 ⑥ ml-tap — a11y 假按钮替代（div onclick → 真按钮）

解决项目里 477 个 <div onclick> 假按钮：键盘不可达、无 ARIA、SEO 不识别。<ml-tap> 提供 role/tabindex/Enter·Space 键盘触发/focus-visible。

3 种 variant × 3 个示例

默认 variant
点击 / Enter / Space 都能触发
tile 方块
适合分类入口、快捷区
ghost 透明
hover 才显示背景

aria-pressed 按下态（可切换 toggle）

默认 · 未按下 默认 · 已按下

disabled 状态

可点击 已禁用

错误容错（onclick 异常不会崩溃）

🎯 window.ml API 速览

// toast
ml.toast.success('已保存');
ml.toast.error('网络异常');

// modal
ml.modal.open('modalBasic');
ml.modal.close('modalBasic', 'api');
const ok = await ml.modal.confirm({ title:'确认删除', message:'此操作不可撤销' });

// tab
ml.tab.setActive('demoTab', 2);
const idx = ml.tab.getActive('demoTab');

// card
const c = ml.card.create({ title:'新卡片', body:'内容', variant:'glass' });

// accordion
ml.accordion.openAll('faqMultiple');
ml.accordion.closeAll('faqMultiple');

// tap (a11y 假按钮替代)
const t = document.querySelector('ml-tap');
ml.tap.disable(t);
ml.tap.enable(t);
ml.tap.press(t);  // 程序触发点击
