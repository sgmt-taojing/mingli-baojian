三、六大支柱建设蓝图

支柱 1：模型进化引擎（命理 + 视觉双线）

命理线：v8.9 推理链修真（评估中）→ v9.x 数据规模扩至 5000+ 条 → rank 8/16 提升容量 → BaziQA 70%
视觉线：YOLO26 为底座 → 垂域模型自训管线（Roboflow 数据集 + R733 工作台）→ 30+ 模型矩阵
关键修真：数据配比经验（推理链 80% + 自由问答 20%）、BaziQA 不去重、真实测试集强制

支柱 2：算法超市全自动运营

爬虫每日扫描（已 cron）→ guard-download 防护 → 权重拉取 → 四维评估（准确率/时延/体积/license）→ 达标自动上架 → 超市页双态展示（已实现）
目标：29 → 50+ 算法，全部「可落地」标注 + 实时状态 API

支柱 3：场景智能组合（规则+模型矩阵）

规则引擎（区域/帧差/停留/统计）× 垂域模型（YOLO26 检测/分割/姿态）→ 组合出 50+ 场景算法
例：消防通道 = detect(person/car) + 停留规则；工地安全 = helmet 模型 + 区域规则；跌倒 = pose + 几何规则
目标：场景级 API（一次调用 = 多算法协同）

支柱 4：医疗健康闭环（差异化高地）

中医四诊（舌/面/手/眼）→ 多模态融合诊断 → 医生审核闭环（已建）→ 应急安全闸门（L0-L3 已建）
人脸核对（512 维）→ 医保对接 → 开药身份核验（已建）
目标：四诊合一报告 + 医保人脸核对全链路

支柱 5：数据飞轮（采集→训练→评估→上线）

R733 采集工作台（已建）→ 增量 SFT 构建 → 训练（已自动化）→ BaziQA/真实集评估 → 上线（plist 切换）
目标：一键「新方向 → 新模型上线」全流程 < 2 小时

支柱 6：工程保障（最高水准的可靠性）

修真三件套（已建）+ pre-commit 钩子 + 13 服务 launchd + 磁盘自动归档策略 + 定时任务自动收尾
目标：零人工值守的自动化运维（服务自愈 + 磁盘自洁 + 评估自动收尾）
