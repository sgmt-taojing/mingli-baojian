# 生肖（属相）知识应用专项诊断

**日期**：2026-08-31 ｜ **范围**：排盘工具解读层 + 知识库 + 民俗/合婚报告

## 一、结论（先行）

**知识储备充足，引擎消费断流。** 知识库已有 251 条生肖直接相关条目、60 条 zodiac 模块（十二生肖性格详解+本命佛）、三合 1268 / 六合 1375 / 六冲 217 / 相刑 227 / 相害 160 条关系知识、taisui 模块 12 生肖逐年太岁条目——但解读引擎三大中枢（engine-interpreters / chart-score-engine / engine-facade）**生肖引用为 0**，核心排盘报告（八字/紫微/六爻）实测生肖应用≈0。这是一片「有弹药、没接上枪管」的领域。

## 三、断点定位

1. **解读中枢零引用**：`engine-interpreters.js`、`chart-score-engine.js`、`engine-facade.js` 生肖/zodiac 引用计数全 0——所有排盘报告的解读生成都不过生肖维度。
2. **知识沉睡**：zodiac 模块 60 条（属鼠男性/女性性格详解等）无任何引擎消费（全 server 仅 api-server-v2.js 检索过 'zodiac'）；taisui 模块「2026 丙午年·X生肖·太岁Y·煞Z」12 条只在太岁工具内闭环。
3. **合婚婚配等级不完整**：norm-report-engine 只有 ZODIAC_CLASH/ZODIAC_HARMONY 两表（六合/六冲），传统婚配的三合（上婚）、六害/相刑（中下婚）未入模型——知识库 hehun 模块 19 条生肖婚配知识未命中。
4. **八字报告的年支盲点**：年支（=生肖）与月/日/时支的三合六合六冲关系、与流年太岁的值冲刑害破，在 14 万字报告里仅偶然出现 4 次「值太岁」，无系统化生肖段落。

## 四、生肖的合理应用维度（按专业边界规划，不过度泛化）

> 专业边界说明：子平八字以日主为太极点，生肖=年支，权重有限——但民俗应用、流年太岁、婚配合作、信众沟通中生肖是**第一语言**。正确做法是把生肖作为「辅助维度层」按传统规则系统接入，而非喧宾夺主。

| 维度 | 传统依据 | 知识库现状 | 接入点 |
|---|---|---|---|
| 年支关系网络（六合/三合/六冲/六害/相刑/自刑） | 地支关系通例 | ✅ 关系词条目 2000+ | 八字/紫微报告新增「生肖关系」段：年支×其余三支、年支×流年、年支×大运 |
| 生肖贵人（三合贵人/六合贵人） | 三合局寅午戌等、六合午未等 | ✅ | 人际/合作/婚配建议；紫微可对应宫位地支 |
| 生肖流年（值/冲/刑/害/破太岁） | 太岁通例 | ✅ taisui 12 条逐年 | 八字/紫微报告流年段自动命中当年生肖太岁条目 |
| 生肖性格画像 | 民俗生肖学 | ✅ zodiac 60 条（男女分述） | 报告性格段引用 + 问事服务中心信众语境 |
| 本命佛/守护神 | 民俗信仰 | ✅ faith/zodiac 模块 | **仅信众版**报告祈福建议段（医学域禁入，R756 红线） |
| 生肖婚配等级（六合上婚/三合上婚/普通/刑害中下/六冲下婚） | 合婚通例 | ✅ hehun 19 条 | 合婚报告升级二态→五档 |
| 生肖喜用（取名部首/幸运色方位） | 民俗生肖姓名学 | ✅ naming 31 条 | 姓名工具改名建议段、缘主幸运建议 |

## 五、补全方案

**P0（引擎层，一次建设全局受益）**
1. 新建 `server/shengxiao-engine.js`：输入年支（生肖），输出关系网络全集——六合/三合/六冲/六害/相刑/自刑（vs 任意支）、三合六合贵人、流年太岁五态、性格画像（命中 zodiac 模块）、当年太岁条目（命中 taisui 模块）。单引擎，全工具复用。
2. 八字/紫微报告接入：新增「▸ 生肖关系」段——年支×四柱、年支×流年太岁、贵人指向、性格画像引述（白话）。
3. 合婚升级五档婚配等级（六合/三合/普通/刑害/六冲），命中 hehun 模块知识。

**P1（工具层）**
4. 问事服务中心：信众提交生辰后，解读自动带「您属X，今年太岁关系…」开场语境。
5. 姓名工具：改名建议接生肖喜用部首维度（naming 模块）。
6. 风水/择日：已有避冲主事人生肖✓，补「三合六合贵人日」提示。

**P2（边界与呈现）**
7. 本命佛/守护神段仅入信众版报告模板，机构版/医学域模板不出现（守 R756）。
8. 前端：八字/紫微报告页生肖段配图标识（禁文字标识红线）。

**预期效果**：激活 251 条沉睡生肖知识 + 2000 条关系知识的消费通道；八字/紫微/合婚三大核心报告生肖维度从零到系统化；信众语境（民间第一语言）与专业语境（日主为纲）分层清晰。
