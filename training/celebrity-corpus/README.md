# 名人八字校正库（celebrity-corpus）

## 定位
全网公开名人八字语料库，用于校正自有智能体与排盘引擎的判断准确率。

## 数据结构（每条样本）
```json
{
  "person_id": "zhugeliang_history_001",
  "name": "诸葛亮",
  "source": "《三国志》/维基百科",
  "source_url": "...",
  "birth": {"year": 181, "month": null, "day": null, "hour": null, "approximate": true, "lunar": true, "place": "琅琊阳都"},
  "facts": {"marriage": [...], "children": [{"gender": "male", "birth_year": ...}], "career": [...], "health": [...]},
  "verified": false,
  "paipan": {}
}
```

## 采集合规红线（永久）
- 只收公开信息（史料/官方资料/公开报道/学术数据集）
- 禁止付费墙内容、禁止违反平台条款的爬取
- 每条来源可溯（source 必填）

## 校正工作流
1. 采集入库（staging）
2. 本地排盘引擎排盘
3. 命理判断 vs 真实生平 → 逐条打分（婚/子/事业/健康四维）
4. 命中率统计 → 错题本
5. 错题 → 纠偏训练集 → 微调迭代（走七条训练纪律）

## 深度校正扩展（R770 · 2026-08-27 23:06）

### 全维度人生事件采集（不设限）
每条样本的 facts 字段扩展为全生命周期事件集：
- 改名/改号（时间+原名+新名）
- 迁居/换城市（时间+城市+方位变化）
- 婚姻（结婚/离婚/再婚年份）
- 子女（性别+出生年月）
- 事业（创业/上市/破产/转型/退休节点）
- 健康（重大疾病/手术/康复）
- 财富（暴富/破产/重大投资节点）
- 官非/诉讼
- 学历/拜师/成名节点

### 反向校正工作流（八字 → 事件 → 校验知识库）
1. 采集名人全事件年表 + 八字
2. 本地引擎排盘
3. **逐事件反推**：该年该月，盘上有何信号？（大运流年流月与宫位十神的互动）
4. 事件与盘面信号比对：
   - 命中 → 该条知识库规则记一分（可信度加权）
   - 不命中 → 错题本（规则错 or 排盘错 or 事件记载错？三级归因）
5. 知识库规则可信度持续调整——高频命中的规则升权，屡屡失准的规则降权复审
6. 排盘引擎同步校正（如真太阳时/早晚子时处理是否与事实吻合）

### 三级归因法（错题处理）
- 规则错：知识库条目本身有误 → 古籍复核修正
- 排盘错：引擎技术问题（历法/时区/早晚子时）→ 代码修真
- 记载错：名人资料本身讹误 → 标注 approximate，不入训练集
