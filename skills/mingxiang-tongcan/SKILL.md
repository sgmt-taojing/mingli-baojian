# 命相同参 · 古制蒸馏知识对外服务（mingxiang-tongcan skill）

> 命理宝鉴 · 相术部古制蒸馏成果的服务化封装。古断存真、标注可溯源、服务层通俗转化——三位一体。

## 定位

把 KB 中 63 条命相细则（KB-MX-001~063，蒸馏自《古今图书集成·艺术典·相术部》卷631-650 公有领域原典）活化成对外服务能力：输入面相/气色/形局/痣斑/声音/掌纹观测，输出与命局同参的白话判读 + 结构化原典引证。

## 调用方式

```
POST http://127.0.0.1:8920/api/mingxiang/tongcan-card
Content-Type: application/json

{
  "qise": "黄",                      // 面色主色：青/红/赤/黄/白/黑/紫
  "xingju": "土形",                  // 形局：木/火/土/金/水形
  "palaces": { "官禄": "明亮", "命宫": "饱满" },  // 宫位观测：明亮/饱满/平满/暗沉/凹陷/纹破
  "moles": "鼻梁有痣",               // 痣斑描述（含部位名自动匹配部位专断）
  "voice": "声音清亮",               // 声音观测
  "palm": "掌纹深长",                // 掌纹观测
  "gender": "女",                    // 性别（女附引女相细则）
  "dayWx": "土",                     // 命局日主五行（互证）
  "shiyong": ["火", "土"]            // 命局喜用五行（互证）
}
```

## 标注体系（每条蒸馏知识四件套）

| 标注 | 字段 | 说明 |
|---|---|---|
| 条目号 | entry_id | KB-MX-NNN，库内唯一 |
| 出处标注 | source | 由 src_id 解析为原典卷目（如《图书集成·相术部》卷636） |
| 古断摘录 | quotes | 原典断语原文，存真不删改（KB-QUALITY-RULES 六） |
| 服务层口径 | service_note | 「批注用法」行——古断→现代通俗转化的纪律说明 |

## 纪律红线

1. **相不独论**：相学观测必须与命局同参互证，单相不断；
2. **分层输出**：古断存真层（archive）与服务转化层（service）同源并列，凶断（法令入口/夺命色等）仅命理师内部参考，禁直出信众；
3. **涉健康挂医师**：气色/痣斑/掌纹涉身体状况一律附「咨询医师」；
4. **签名权在人**：输出只进批注层/报告层，供命理师审改，不自动成断语。

- 宫位五官层：十二宫诀、额/眉/眼/鼻/口/耳细则
- 形神形局层：五行正形、形局宜忌、神气论
- 专项层：痣斑部位专断、声音、女相（九善九恶/女德论）、掌纹（三纹九宫/许负相手）
