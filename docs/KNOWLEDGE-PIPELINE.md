# 知识构建方法论：古籍 → 蒸馏 → Skill → 活化（R-KB-PIPELINE · 2026-10-09）

> 命理宝鉴知识库构建的 canonical 管线。由相术部十五批（MX-001~125）与紫微细则（ZW-001~013）
> 实战验证后定型。任何新学部/新古籍入项目，按此管线走，不另起炉灶。

## 一、管线全景（六层 + 一闭环）

```
L0 寻源净本 ──→ L1 原典入库 ──→ L2 蒸馏细则 ──→ L4 Skill 封装 ──→ L5 活化服务
                    │                │                                  │
                    ↓                ↓                                  ↓
               版本对勘          L3 质量校验                        L6 反馈回路
               禁二手拼接        五红线+对账+基线              错题归因→差集→回 L2
```

用户原始逻辑「古籍→蒸馏→skill→活化」方向正确，实战补齐三个环节：**L0 净源前置**、**L3 校验层**、**L6 反馈闭环**。

## 二、各层职责与铁律

### L0 寻源净本（前置，不可省）
- 版本考据优先：四库本/道藏本/嘉靖刻本等公版净源，多版本对勘（如太清神鉴 KR 四库本×WS 维基本）；
- **禁拼接二手**：现代点校说明、转述二手不入库（相术部「路总藏书」2 条排除在案）；
- 拿不到净源的书目进「待净源书单」挂账，宁可空缺不凑数。

### L1 原典入库（存真层）
- 原文 chunk 入库（KB-KJZW 模式：页段命名 `nXXXX-XXXX|cNNN`），**一字不改**；
- OCR 散页作检索冗余保留；质量不过关的源（mingban/nbshanren）重 OCR 后再入。

### L2 蒸馏细则（结构化层）
- 每条细则**标注四件套**：条目号（KB-XX-NNN）+ 出处标注（src_id→原典卷目）+ 古断摘录（◆ 原文照录）+ 服务层口径（【批注用法】）；
- **指纹幂等**：内容指纹去重，脚本可复跑不产生重复；
- **古制存真红线**：凶断（夭/刑克/牢狱等）全标「存真·仅命理师内部参考」，涉健康挂「咨询医师」，时代文本（女命旧语）存真不改写——研究层保真，服务层才转化；
- **覆盖清单对账**：每学部一份 COVERAGE 文档（docs/*-COVERAGE-*.md），批次/细则/原典三方对账，差集驱动下一批。

### L3 质量校验（独立层，不过线不入库）
- **五红线巡检**（kb-quality-patrol）：主表=fts5 同步、NULL 键为零、重复组收敛、空摘要为零、域标完整；
- **引擎交叉校验**：能算的用引擎复核（如命图 114 盘五虎遁独立复盘，15 盘差异以图为准并回写 note）；
- **评测基线**：能力类变更过题库基线（new100 纯净基线，放行门 −2pp / 有效提升 +3pp）；
- **预检纪律**：外部服务依赖（8960 推理）先探活再跑批，杜绝假成绩（10-08 事故在案）。

### L4 Skill 封装（服务接口层）
- 细则不直接对外——经 skill 封装成服务契约（如 mingxiang-tongcan：观测输入→白话判读+结构化引证）；
- 接口契约稳定：蒸馏批次扩充不改 API 签名。

### L5 活化服务（输出层）
- 引擎引证（KBREF 映射：观测项→细则条目，观测特异优先，上限 8 条）；
- 报告层/批注层/推送层共用同一引证源；
- **签名权在人**：输出只进批注/报告层供命理师审改，不自动成断语；
- 分层输出：存真层与服务层同源并列，凶断不进信众面。

### L6 反馈闭环（进化机制）
- 评测错题归因（ATTR 系列：位置偏差/心算缺陷/十神断裂/应期 doctrine 缺口）→ 差集清单 → 回 L2 定向补蒸馏；
- 连续两轮差集无新增 → 该学部转常态（相术部 2026-10-09 已达）。

## 四、新增学部 checklist

1. L0：净源到位？版本对勘记录？→ 否则进待净源书单
2. L1：原典 chunk 入库，页段命名规范
3. L2：COVERAGE 清单立账 → 分批蒸馏（每批 ≤15 条，脚本+四件套+存真标注）
4. L3：五红线过线 + 覆盖对账 + 涉引擎的交叉校验
5. L4/L5：skill 封装 + KBREF 引证接线 + 实测用例（全要素/降级各一）
6. L6：挂入评测或巡检节奏，错题归因回 L2
