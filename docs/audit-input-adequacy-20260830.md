## 六、横向系统性问题（跨工具）

| # | 问题 | 严重度 | 细节 |
|---|---|---|---|
| H1 | 时辰未知默认值不统一 | **P1** | need='birth' 默认午时 12（中性，合理）；namebirth/textopt/rename/company 默认 **0（子时）**——子时换日界 + 改变时柱五行计数，起名/改名/手机号契合度会被静默带偏 |
| H2 | 时辰未知无披露 | **P1** | 用户不填时辰时报告未声明"按午时推算，时柱相关结论（子女宫/晚年运）仅供参考"；引擎与白话层均无 hourUnknown 概念 |
| H3 | 八字流不支持农历输入 | **P1** | ziwei 有阴阳历切换，bazi/lifeindex/lifeflow/lifetimeline/lifeplan 没有；中老年信众很多只知农历生日 |
| H4 | 真太阳时入口未开放 | P2 | 引擎支持 lng/minute（奇门/六壬/紫微均接），前端无出生地采集；对时辰临界盘影响实质 |
| H5 | 摇卦/报数起卦入口未开放 | P2 | 六爻 coins、梅花 num1-3 引擎已支持，前端仅时间起卦 |
| H6 | 命格指数/人生规划引导文案与校验不符 | P2 | 文案"出生年份+性别"，校验要求年月日齐全 |
| H7 | 风水缺建造/入住年份 | P2 | 无运盘则飞星断不准；当前输出为八宅级，报告未明示此限制 |
| H8 | 起名未采集避讳字/字辈 | P3 | 引擎支持，前端未采 |
| H9 | 择日/太岁/黄历个人化 | P1 | R-PERSONAL 修复在途（helper 已插入 server，端点接线待完成） |

## 七、结论

- **采集充足（✅）**：13/28 工具——奇门、六壬、流年运势、流年报告、十年走势、合婚、改名、公司取名、姓名评分、手机号、车牌、人生规划、节气、节日、家庭。
- **勉强可用（🟡）**：六爻、梅花、宝宝起名、幸运数色、黄历——均有"明示降级"空间。
- **硬缺口（🔴）**：八字（农历/时辰披露/真太阳时）、紫微（时辰强制/闰月）、风水（建造年份/精度）、择日+太岁（个人化）。
- 最严重的是 **H1 子时默认**：它在信众毫无感知的情况下改变命局五行计数，直接污染起名/改名/手机号三个"命局契合"卖点工具的结论。
