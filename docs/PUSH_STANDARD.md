# 命理宝鉴 · 每日推送规范（R143 固化版）

> 综合 2026-08-18 全部修真要求 + 互联网合规调研，正式固化。
> 生效范围：缘主版（full）/ 大众版（public）/ 速览版（simple）/ 节日节气版，及每日晨推 06:00 / 晚推 18:00。

---

## 一、内容总原则（用户强制）

1. **去AI味**：口语化、大白话，禁止套话鸡汤、堆砌术语
2. **极简**：重点突出、细节指导、不啰嗦；full≤3000字 / public≤1600 / simple≤700
3. **结构化**：板块固定、信息各归其位、零重复
4. **拿来即用**：每条建议必须是可执行动作（①约人②推进③收尾），带时段/分钟数
5. **日常指导**：服务日常生活，不搞玄虚

## 二、固定结构（缘主版）

```
① 缘主命盘（我是谁）——四柱/五行/喜忌/大运/生肖/流年
② 年度格局（今年大框架）——流年十神×大运互动×当前月提醒
③ 今日定义（今天是什么日子）——天干意象×建除定性
④ 今日要义 + 五层联动——年→月→季→日→时
⑤ 全天剧本——🌅起手 / ☀️开展 / 🌙收尾（每段带时段+动作）
⑥ 今日运势——评分+适合/少碰（编号动作）+提气+穿搭方位
⑦ 黄历结论——宜忌归类结论+吉凶计数+吉时带宜事+天气+养生+节气
⑧ 修身（照命盘）——古籍口诀+补弱/增旺/化忌三件套+咒语+大运背景
⑨ 标准免责
```

## 三、数据规范

1. **权威源**：黄历/干支/神煞/彭祖/纳音/星宿全部 lunar_python 实时 API，禁止手抄表（有API不用手抄表）
2. **活数据禁轮换**：知识从 yidao.db（14000+条）按当天特征（日期/日干/五行）实时检索；本地库仅断网兜底
3. **古籍口诀**：按 M月D日 精确匹配 koujue-daily（《滴天髓》《渊海子平》347条）
4. **可执行化**：吉时带宜事（青龙→见贵/司命→开市）、方位落动作（办公桌朝东）、化解到分钟
5. **禁死循环**：内容组合必须随日干活变化，30天0重复为验收线

## 四、个性化规范（缘主命盘：癸水·喜木火·忌金水·木最弱）

1. **补弱**：木→养肝动作/绿色/东方/仁爱经典
2. **增旺**：土金→诚信稳重/果决/发挥优势
3. **化忌**：金水→火克金（晒背穿红）/土制水（防破耗）
4. **冲本命识别**：当日冲缘主生肖→要义首条⚠️+评分压档≤55+全盘转守势
5. **五层联动**：流年（正财年）/流月（财透印藏）/季节（秋金忌神季）/当日（黄历）/吉时（最利你）

## 五、合规边界（互联网调研补充 · 强制）

1. **禁绝对化**：不用"一定/必定/注定/必然"，用"倾向/容易/信号显现/建议留意"（《广告法》绝对化用语禁令）
2. **健康仅趋势参考**：不诊断、不治病、不提供迷信治疗建议；必须带"身体不适请及时就医"（《互联网诊疗管理办法》边界）
3. **投资仅参考**：不构成投资建议，重大决策本人负责
4. **不预测寿元**：严禁断寿元、断生死
5. **不恐吓**：禁止恐吓性语言（防"割韭菜"式诱导）
6. **不推销**：不推销法器/付费化解/开光物品（行业乱象警示）
7. **明示参考性质**：定位"传统文化交流/生活参考"，标准免责强制输出
8. **平台兼容**：全篇符合内容生态治理要求，不宣扬迷信、不涉医疗法律专业建议
