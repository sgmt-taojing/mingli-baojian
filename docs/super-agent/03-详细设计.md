### 1.3 会话状态机

```
idle → identify(身份) → intake(问答采集) → confirm(信息确认)
     → compute(引擎) → retrieve(KB) → draft(三段报告) → present
     → feedback(授权存档/校正点登记) → idle
任意节点用户说"重来"→ 回退上一节点；说"换工具"→ 回 intent 路由。
```

### 1.4 Prompt 资产结构（server/prompts/curator/）

```
curator/
  system.md            # 馆长人格+红线+自述来源规范
  route.md             # 意图分类器 prompt（输出 JSON:intent+slots）
  intake/{tool}.md     # 各工具追问脚本（28+7 份，字段从 schema 生成）
  report/
    professional.md    # 专业段（术语/引文/出处）
    plainfolk.md       # 白话段（比喻/短句/无恐吓）
    action.md          # 行动段（改进建议=具体可做清单）
  coach/case-review.md # 副驾评点（按原典条文打分）
  teach/quiz.md        # 导师出题批改
```

## 二、校验体系详设

### 2.1 三级校验

| 级 | 对象 | 基准 | 节奏 | 门禁 |
|---|---|---|---|---|
| L1 题库 | 模型/引擎 | BaziQA 488 题（v94 后选项洗牌重建 v2） | 每次变更 | 快测 30 题≥前基线 |
| L2 名人 | 报告质量 | wiki 702 生辰事件库（事件补齐后 600+ 样本） | 周 | 深度校验不回归 |
| L3 真人 | 实战应验 | 校正库（授权回收） | 月报 | 命中率公示 |

### 2.2 校正库 schema（feedback_points 回收）

```sql
CREATE TABLE IF NOT EXISTS kb_calibration (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  report_id TEXT, person_alias TEXT, tool TEXT,
  claim TEXT, claim_dim TEXT,       -- 预测点+维度
  due_date TEXT,                    -- 应期
  outcome TEXT,                     -- hit|miss|partial|pending
  outcome_note TEXT, created_at TEXT, verified_at TEXT,
  consent INTEGER DEFAULT 0         -- 授权标记
);
```

### 2.3 题库 v2 重建要点（v94 教训）
- 选项随机重排后重哈希答案键，消除 B 偏斜（目标各选项 20%±5）；
- 每人 10 题维度配平：感情/财富/健康/六亲/事业 各 2 题；
- 答案依据写入 evidence 字段（可审）。

## 三、传承学堂详设

### 3.1 课程包结构

```
courses/
  bazi-101/           # 八字入门
    meta.json         # 标题/对象/课时数/先修
    outline.json      # 章节树（AI 从典籍生成，命理师审）
    lessons/01.md     # 课文（原文引段+白话讲解+图示）
    quiz/01.json      # 随堂测（选择+简答，AI 批改）
```

### 3.2 首批三门（一期）
1. **八字入门十二讲**：穷通宝鉴调候+神峰通考格局（净本已在库）。
2. **六壬案例研讲**：断案 222 案精选 30 案（前程/疾病/官讼各 10），配指南理论段。
3. **紫微安星诀**：紫微全书 3 卷净本 + r45 系列条目。

### 3.3 段位认证
学徒（课程测验≥80%）→ 习者（案例陪练 10 案命中≥6）→ 先生（50 案+真人校正 20 例）→
认证数据只用于学习激励，不构成执业资格声明（合规话术）。

## 四、知识图谱数据模型

### 4.1 节点类型
`book(典籍)` / `module(知识域)` / `entry(条目)` / `engine(引擎)` / `tool(工具)` /
`course(课程)` / `person_case(校正案例)` / `model(模型版本)`

### 4.2 边类型
`distilled_from`(条目←典籍) / `belongs_to`(条目→域) / `powers`(域→引擎) /
`consumed_by`(域→工具) / `teaches`(典籍→课程) / `validates`(案例→模型) /
`cites`(报告→条目)

### 4.3 落地
- 快照 JSON：`docs/super-agent/knowledge-graph-20260926.json`（本次盘点数据）
- 可视化：app/project-knowledge-graph.html 换数据源重渲染（增量任务 S-3.2）。

## 五、API 设计（curator-api :8980）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/curator/session | 开会话（身份声明+年龄声明） |
