## 一、立项背景与高度

### 1.1 为什么是现在

1. **传承断代危机**：术数传承依赖师徒口耳与古籍自修，一名合格命理师养成需 10–20 年。
   人口出生率下行、从业人口老龄化，未来 20 年愿意且能够入门的学习者将持续减少——
   **不把知识结构化、能力引擎化、智慧模型化，五千年积累将在一两代人内实质性失传**。
2. **AI 窗口期**：大模型第一次让「古籍 → 结构化知识 → 可计算推演 → 白话服务」的全链路
   自动化成为可能。谁先完成知识底座与校验体系，谁就定义命理 AI 时代的标准。
3. **本项目已具备先发底座**：31.9 万条知识库、排盘七术引擎、50 名人 488 题校验基准、
   微调模型管线、五中心服务界面——不是从零起步，而是从底座走向体系。

### 1.2 项目高度

- **对文明**：做术数知识的「数字藏经阁」+「活态传承机」，原文不改写、出处可溯源、理论可计算。
- **对行业**：制定命理 AI 的知识标准、校验标准、服务标准；命理师从「记忆者」转型为「审核者与人文者」。
- **对大众**：信众/缘主/大众以问答式零门槛获得专业、白话、可行动的服务；不诱导、不恐吓、未成年人禁入。
- **对未来**：当学习人口进一步缩减，AI 就是最大的「弟子」——它已读完全部典籍，且永不遗忘。

## 四、建设内容（三期）

### 一期：知识补齐 + 馆长智能体骨架（0–3 月）
1. 知识密度翻倍计划（进行中）：稀薄模块按 G26 SOP 多轮蒸馏清零；
   六壬域双璧已闭环，续取奇门统宗、择日通书、相术三书（麻衣/柳庄/冰鉴）。
2. 馆长智能体 MVP：统一对话入口，意图识别 → 引擎调度 → KB 检索 → 报告生成。
3. 校验升级：题库选项洗牌平衡（v94 暴露 B 偏斜）；wiki 702 事件补齐；校正库破千。

### 二期：传承体系 + 命理师指导（3–6 月）
1. 传承课程引擎：典籍 → 课程大纲 → 章节 → 课时分镜 → 随堂测验（AI 出题批改）。
2. 命理师副驾 2.0：实占陪练（AI 扮命主出案例，命理师断，AI 按原典评点）；
   断案 222 案 + 指南 125 案为第一批案例库。
3. 万人校正库：信众授权回收「预测-应验」反馈，形成活校验流。

### 三期：生态与标准（6–12 月）
1. 能力发版常态化（G21 已建）：命理能力包月窗发版，家庭端/合作机构同步。
2. 开放标准：知识条目 schema、校验基准、服务话术三层标准文档化，可供行业采用。
3. 多模态传承：古籍扫描件 ↔ 净本对照阅览器；名家讲课音视频蒸馏（倪师天纪已分类）。

## 五、合规与红线（不可协商）

- 医学/命理分域：诊疗链路只命中 tcm 正室，命理批注只在批注层合流（R745/R756/R757/G24）。
- 服务话术：机构版/消费者版分层；不诱导、不恐吓；化解建议给行动方案不给灾祸渲染。
- 未成年人禁入信众体系（注册年龄声明 + 18 禁入）。
- 原典知识「原文不改写」，白话解读另段标注「解读」，永不混排。
- 知识入库铁律：蒸馏入 KB ≠ 模型训练；指纹幂等去重；二手拼接网文一律不收。
