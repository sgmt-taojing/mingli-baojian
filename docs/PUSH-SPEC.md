# PUSH-SPEC · 每日推送内容规范（MB-M1 v2 固化 · 2026-09-26）

> 本文件是每日推送（晨推/暮推/极简版）内容规矩的唯一载体。
> 修订规矩 = 改本文件 + CHANGELOG 记录，不再有外部任务书。
> 实施文件：`daily_push.js`（结构）+ `server/daily-push-bridge.py`（数据层）+ `server/daily-recommendation.py`（缘主完整版）。
> 发送链路：launchd push-morning 06:00 / push-evening 18:00 → scripts/push-run.sh → daily_push.js → scripts/push-queue-enqueue.py（≤1800B 分段，支持 ━━━SPLIT━━━）→ wecom-aibot daemon → 企业微信。

## 一、内容硬伤防线（E1–E6，逐条可验收）

### E1 古籍口诀日柱闸口
口诀上版前必须命中当日日柱。柱煞适用表：

| 柱煞 | 适用日柱 |
| --- | --- |
| 十恶大败 | 甲辰、乙巳、丙申、丁亥、戊戌、己丑、庚辰、辛巳、壬申、癸亥 |
| 阴差阳错 | 丙子、丁丑、戊寅、辛卯、壬辰、癸巳、丙午、丁未、戊申、辛酉、壬戌、癸亥 |
| 孤鸾 | 乙巳、丁巳、辛亥、戊申、甲寅 |
| 魁罡 | 庚辰、庚戌、壬辰、戊戌 |
| 四废 | 春（寅卯辰月）庚申/辛酉；夏（巳午未月）壬子/癸亥；秋（申酉戌月）甲寅/乙卯；冬（亥子丑月）丙午/丁巳 |

- 口诀文本提及柱煞但当日日柱不在适用表 → 视为不适用，自动换吉祥类口诀（分类吉/合/贵/贵人）。
- 口诀出处原文入库可回查（koujue-daily 模块【口诀】【出处】【释义】三段式）。
- 实施：`daily-push-bridge.py _pillar_mismatch()` / `daily-recommendation.py` R784c 块内闸口。
- 反例存档：2026-09-26 癸卯日曾被误标「十恶大败」。

### E2 三级矛盾裁决
优先级：**黄道黑道 > 建除十二神 > 古籍口诀**。

- 低优先级与高级冲突时，不上文或改写为「虽逢×，总体从×」句式（`verdictLine()`）。
- 吉神数 < 凶煞数时，全篇禁止「诸事顺利」类句子，基调压档为「守」。

### E3 分数定调
运势分（`DR.calc_fortune_score` 可解释模型）：<60 全篇基调「守」；60–80「稳进」；>80「进取」。
今日三要、运势量化、时辰剧本共用同一基调变量（`toneOf()`），不得互相打架。

### E5 落款唯一
固定两行，无重复 slogan：

```
—— 🪷 易道智鉴 · 节气养生 ——
⚠️ 本内容仅命局趋势参考，重大决策由本人自行负责；医疗、投资、法律问题请咨询专业人士。
```

### E6 五行口径
五行计数行注明口径（如「（口径：含藏干）」），一行小字。

## 二、结构规范（命主：癸水·雨露之水·喜木火·忌金水·乙丑大运·丙午流年）

### 晨推（当天作战图）——R-SLIM 五板块（2026-09-27 精简改版：轻重缓急+只留缘主/信众相关+全白话）
1. **今日定调**（分数+基调+裁决白话+黄金窗口，全篇最高优先级，其余板块不得与之冲突）
2. **跟您有关**（日干十神对缘主+喜忌行动一句；冲煞分级：正冲缘主生肖（羊）重提醒/否则一句带过；五运六气底色一行）
3. **宜忌速办**（宜3/忌2 带白话+建除黄黑道一行+神煞精选 2 吉 2 凶带注解）
4. **节气/节日/神仙诞辰/每日一课**（有则出，信众向）
5. **修身一句**（一引用一行动，口诀必须已过 E1 闸口）+落款免责（E5）
- 已砍：时辰剧本三行（折进黄金窗口）、运势量化独立板块（并入定调）、速查区（星宿/方位/天气/吉时长串——与命理决策无关）、神煞长串（改精选）。

### 暮推（--tomorrow，明日预告+今夜收整）——R-SLIM 五板块
①明日定调（分数基调裁决+宜忌+黄金窗口+建除）→ ②跟您有关（冲煞分级+神煞精选）→ ③五运六气·天赋底色 → ④今夜收整三件事 → ⑤修身一句 → 落款+免责。

### 术语纪律
专业术语首次出现必带半句白话（对齐「癸水日·雨露之水」实践：如「比肩（帮扶平稳）」「食神（温和泄秀，利作品产出）」）。

### 节日预告
唯一来源 festival 数据（HOLIDAYS / LUNAR_HOLIDAYS / festival_calendar 表），任何文档/代码禁止写死具体节日文案。

## 三、分段标记（治「内容不完整」）

- 输出中按板块边界插入独立一行 `━━━SPLIT━━━`。
- 晨推切点固定（R-SLIM）：①今日定调+②跟您有关｜③宜忌速办+④节气节日+⑤修身+落款（2 段）。
- 每段 ≤1800B（分段器实测上限 1,784B）；暮推体量小，单段即可，不强制标记。
- 无标记也能发（按行兜底），但标记模式阅读体验最好。

## 四、验收（裁判核销制）

1. `node daily_push.js verify` 与 `node daily_push.js verify --tomorrow` 全绿（11/11）。
2. 贴出当日完整演示输出：分段标记版全文 + 各段字节数。
3. 裁判对照 E1–E6 逐项核销；通过前 launchd 维持简版，通过后放行 full 版并恢复早晚双推。
