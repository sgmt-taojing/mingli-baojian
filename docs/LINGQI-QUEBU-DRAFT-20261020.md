## 八课原文（维基文库本照录）

### 第 97 课 微損卦 求安之象（课形 1-0-1）

```
二陽相隔 乾天西北

象曰：
登樹採桑，墮地僕殭，
東鄰有藥，走往問方，
因遇良醫，得不損傷。

詩曰：
欲履平途反遇難，若求名利不如閒，
憂中喜遇良醫手。留得殘生在世間。
```

### 第 101 课 空亡卦 缺望之象（课形 2-0-1）

```
陰陽反覆 震雷正東

象曰：
入水伐木，登山捕魚，
損工失力，手空口虛。

詩曰：
寶月盈時缺．長河濁且清，
縱然無咎害，也恐惹虛驚。
```

### 第 108 课 遠襲卦 逃散之象（课形 3-0-4）

```
陰陽隔位 艮山東北

象曰：
追捕寇亡，乃至樂浪，
收我寶玉，牽我中羊。

詩曰：
—牛兩尾事難全。名利順防兩不圓，
遇得木人方有氣。或逢水上亦相便。

又：
縱然心無厭，誰知不兩全。
殺人雖有恨，自亦損三千。
```

### 第 116 课 死象卦 凶兆之象（课形 4-0-0）

```
重陰反位 坤地西南

象曰：
人生有死，鬼氣乃興。
四時代謝，寒暑相承。
沉蔽不顯，其體陰凝。

詩曰：
燕雀動簾幃，驚回夢已違。
幽窗弗管事，也惹是和非。

又：
病入膏肓氣將絕，魄散魂離脈懼歇，
百年相計等閒拋，縱有盧醫不能活。
```

### 第 119 课 人事勢 大怏之象（课形 0-3-0）

```
盛陽處中 乾天西北

象曰：
人事方起，吉無不利。
居者得福，行者必至。

詩曰：
居家多有慶，富貴得平安：
萬事從心起、都來好處看。
```

### 第 120 课 保身卦 小安之象（课形 0-4-0）

```
積陰居中 坤地西南

象曰：
鬼氣未盛，厲毒未形。
保慎性命，門戶安寧。

詩曰：
花逢春雨難留艷，水逐東流怎複波？
若把利名前路去。卻防閒事暗憂多。

又：
花開春又去，蝶來花已殘。
惟有青青柏，終能耐歲寒。
```

### 第 121 课 化育卦 生氣之象（课形 0-0-1）

```
孤陽不明 乾天西北

象曰：
明明上天，照臨下土。
化育群生，開發門戶。
事皆豁然，更相瞻睹。

詩曰：
已到平安地，江山萬里程。
綠楊芳草路，風快馬蹄輕。
```

### 第 125 课 陰饅卦 無形之象（课形 0-0-0）

```
象曰：
陰饅無象，兆狀未形，
動而有侮，退保其貞。

詩曰：
逢時多難戰兢兢，戒懼當知履薄冰。
要識前程危與險、不籠風裏一枝燈。
```
