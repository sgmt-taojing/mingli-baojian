## 三、回填规则（脚本 training/backfill-yuxiaji.py，可参数化复用）

1. **category ← 典籍名**（单值，书名本体；多版本在 src_id 区分）。
2. **keywords 追加四组标签**（幂等，不覆盖原词）：
   - 典籍标签：书名 + 「古籍原文」
   - 门类标签：择日/八字/易卦…（与 domain 一致）
   - 宜忌分型：题名含「吉日/宜」→吉日；含「忌/凶」→忌日；「占」起→占法；余→宜忌
   - 适用场景：题名关键词映射十场景（婚嫁/营建/葬事/出行/产业/祈禳/人事/占候/神煞宜忌/医药子息）
3. **JSON 数组型 keywords 先解析再合并**（历史数据两种格式并存，204 条已清洗）。
4. 红线：只动 category/src_id/keywords/updated_at；title/content/summary 一字不改。
