# 古老文化 AI 化传承工程总纲（R804 · 2026-09-20）

> 用户令：命相同参和五运六气，以及已拥有的命理和医学知识，全面 AI 化，适应时代需求，
> 沉淀知识和能力，为现代与后世提供传承，发扬光大造福一方。
> 本文件是该项目群的宪法：所有子工程按此对齐，不做散点开发。

## 一、使命定位

把「命 · 相 · 卜 · 山 · 医」五术体系中已拥有的知识资产，转化为**三层可传承资产**：
1. **知识层**：结构化 KB（可检索、可溯源、分域隔离）——已有 31.6 万条底座
2. **能力层**：可计算引擎（输入生辰/八字/面相/症候 → 输出可靠推演）——本工程主战场
3. **智慧层**：微调模型（命理 SFT 已有 v9.0@8960；持续按 BaziQA 管线迭代）

## 三、五运六气 AI 化（P1 · 本期落地）

运气学说 = 中医的时间医学：《内经》七篇大论，以干支纪年推演岁运（五运）、司天在泉（六气）、
主客加临 → 推演年度/季节的气候物候与多发病规律 → 给出养生防治方向。

**可计算性论证**：五运（甲己化土等）与六气（巳亥厥阴风木等）均为干支的确定性映射——
完全可程序化推演，无玄学不确定项。

**工程三步**：
1. **运气管线引擎**（yunqi-engine.js）：输入公历年 → 干支纪年 → 岁运/司天/在泉/主客六步气 →
   年度气化特征 + 易发病脏腑倾向 + 养生调摄要点。输出对接每日推送（节气养生段升级）与报告引擎
2. **知识增厚**：从《类经》运气篇参考域蒸馏「正解」条目入 yangsheng/yunqi 域（标注典籍出处），
   结合夜间蒸馏「节气养生/五运六气」主题池
3. **命理融合**：命主生年岁运 + 当前流年运气叠加（大运×岁气），给「本年个人化养生重点」——
   与现有命盘推送融合，是「应时专业针对」的下一级精度

**边界**：运气推演输出为养生调摄参考，不涉诊疗口径（G24 红线不变）。

## 四、命相同参 AI 化（P2 · 排期）

1. 相术知识体系化：麻衣/柳庄/冰鉴 等典籍蒸馏入库（现散点 89+5 条 → 体系化 500+ 条）
2. 相-命融合引擎：面相特征（face-ocr 已有结构化输出）× 八字命盘 → 命相同参报告
   （如：眉相藏胆气 × 七杀坐命 → 判断勇气格局，双证据交叉验证）
3. 视觉 × 知识闭环：face-ocr 识别特征 → 相术 KB 匹配 → 命相同参段（复用 KB 匹配管线）

## 五、传承机制（持续运转）

- 蒸馏双轨：夜间 web 蒸馏（时效知识）+ G26 月度 SOP（典籍体系化）
- 质量守卫：R793 五红线 + R798 伪托检测（AI 生成引用必须验证书名篇目真实性）
- 三化纪律：模型化（可计算）→ 结构化（KB 条目带出处）→ 口语化（推送口语表达）
- 模型迭代：命理 SFT 每季度按 BaziQA 管线进化一版（现 v9.0 生产）

## 六、验收总纲

每个子工程交付 = 引擎可跑 + KB 有源 + 推送/报告实际引用 + patrol 全绿。
以「现代可用、后世可查」为终极标准：知识条目带典籍出处，引擎带自检用例，模型带评估成绩单。
