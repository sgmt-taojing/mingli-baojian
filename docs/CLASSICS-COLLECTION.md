## 采集 SOP

1. 按本清单逐部抓取（维基文库走 api.php?action=parse 纯文本；ctext 抓正文页）；
2. 净本落 `knowledge/classics/<书名>.txt`（保留版本注记：来源 URL + 抓取日期 + 底本）；
3. 过蒸馏管线（trust 0.7，`SRC-CLASSICS-WEB`，指纹幂等）→ kb_staging → 审核晋升；
4. 三命通会卷十至十二、紫微卷七批命活套两处**定向缺口**优先（挂 P3-B/P3-C）；
5. 每部采集后在台账《稿件提取台账.md》续行登记。
