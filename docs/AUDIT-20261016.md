# 第三轮 · 2026-10-16 深夜（SVG 服务端盘图一致性核查）

## 一、真 bug：紫微年干支显示与内核矛盾（已修，server 36a246a）

- **病灶**：ziwei-iztro-core.js 从 iztro `chineseDate` 提取年干支的正则要求「×年」格式，但 iztro 实际返回四柱空格分隔（「己巳 丁丑 庚辰 辛巳」）**无「年」字**，正则永不命中 → 回退阳历年直推。立春前生人（如 1990-01-15）盘体按己巳排（宫干丙寅、四化武曲禄全部正确），显示层却写庚午——用户保存的 SVG 盘图年干支与盘上一切信息自相矛盾。
- **修复**：优先取四柱首柱（年柱），兼容旧格式，阳历年直推仅作最后兜底。
- **回归实测**：立春前 1990-01-15 → 己巳 ✅ 宫干支/四化/命宫不变 ✅；立春后 1990-05-15 → 庚午 无回归 ✅；农历输入正常 ✅；SVG 标题/信息栏同步 己巳 ✅（盘内「庚午」系己年五虎遁午宫宫干，非年柱，已鉴别非 bug）。
