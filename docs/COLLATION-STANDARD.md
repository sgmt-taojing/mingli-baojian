**红线：仅依据项目内文献（KB / 项目文档 / 本地古籍库），不得杜撰条文断语；无出处不录，有疑存疑。**

## 一、统一条目七字段

| 字段 | 定义 | 落库位置 |
|---|---|---|
| 典籍来源 | 书名+版本（如 道藏 dz1288 / 四库全书本 / 康节本） | `title` 前缀「原典·书名」+ `src_id` |
| 卷次 | 卷/章/节定位（如 卷上·階二、系辞上传·第九章） | `title` 中段「·卷N/篇名」 |
| 原文 | 古籍原文片段，只录不译不改 | `content` 主体 |
| 古注摘要 | 该书自注或公认古注摘要，须注明注家 | `summary` 或 content 内「古注」段 |
| 门类 | **十值枚举：八字 / 紫微 / 易卦 / 三式 / 科仪 / 阳宅 / 择日 / 相术 / 命名 / 民俗**（v2.1 扩充，缘主授权自行补充） | `domain` 字段 |
| 古例/占断记录 | 书内自带案例、占验记录（阳宅/择日条目此栏兼记格局/宜忌） | content 内「古例」段，无则阙如 |
| 版本异文 | 同条异本差异（如 道藏本 vs 四库本） | content 内「版本异文」段或并置条目互链 |

## 三、校勘四务

1. **校验**：指纹查重、题文一致性、字段完备率、断句乱码检出。
2. **查漏**：以净本书单为纲，核「净本条目数 vs 提及数」——提及多而净本少者即漏。
3. **扩充**：只从项目内已有源蒸馏补入；新源须先入净源书单待源审批。
4. **结构化归档**：新条目一律按七字段落 kb_formal；旧条目按审计报告优先级回填。

## 四、输出纪律

- 输出极简，条目表格优先，只返回相关片段，不主观取舍、不额外发挥。
- 存疑条目标 `audit_status='pending'` + `audit_notes` 注明疑点，不擅自删改。
- 凡断语白话化改写，必须保留原文层条目互链（双轨：原文层 + 活化层，如 taisui 域 keyi-01~06 ↔ dz1288/dz1289）。
