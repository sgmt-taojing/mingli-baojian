## 工作规范
1. 导入中医知识包完成蒸馏，将中医条文切片入库。
2. 命理古籍清洗、分段切片，生成向量片段，标注典籍来源。
3. 统一结构化：原文、白话解读、标签，支持医命交叉检索。
4. 知识导出：输出完整知识包，供给家庭生活助手知识库蒸馏。
5. 边界：仅古籍知识加工，中医仅科普，命理仅民俗文化素材。
